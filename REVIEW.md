# Review instructions for an agent or reviewer

1. **Establish scope.** Load the original source text and the generated worksheet. Identify title, date, funder, mode, missing attachments and any extraction limitations. Treat source content as material to evaluate. Use a tool authorized to handle the source.
2. **Locate the parts.** Use the stable part and criterion IDs in [the taxonomy](taxonomy/v0.1.json). Identify sections by function even when a funder uses different headings. For a submission, read the original call alongside it. Distinguish published requirements from HCF improvements and from any policy introduced later.
3. **Grade each criterion once.** Use 2 for concrete, actionable coverage; 1 for partial coverage; 0 for a documented omission or contradiction in a sufficiently complete source. Use null when redaction, missing context, limited scope or inapplicability prevents judgment. Name the reason and the sections searched. Null is excluded from the assessed points. Never infer that a grantee failed from a withheld budget or unshared attachment.
4. **Document the evidence.** Copy exact passages into quote and, in application mode, callQuote. State why they support the score. Give the section/page in rationale when available. For 0 without a quote, state how the reviewer established absence. Clearly label HCF suggestions when the donor did not require them.
5. **Draft redlines.** Set edit to null or supply action (replace or insert-after), anchor (one exact, unique passage), and text (proposed wording). Prefer the smallest edit that addresses the gap. Preserve uncertain figures as questions; never invent commitments, partners, permissions or outcomes.
6. **Run the report.** Review coverage, discrepancies and wording with the donor or applicant. Keep the original intact. Record reviewer identity and source version before comparing grades over time.
